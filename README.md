# Asansorde Yanlis Kata Basma Pismanlik Motoru

Bu depo, modern sehir hayatimin en sessiz trajedisini olcer:
**asansorde 7 yerine 17'ye basmak.**

Proje; uluslararasi asansor hukuku, evsel utanc sosyolojisi ve parmak etiigi uzerine kurulmustur. Hicbir akademik kurum bizi tanimaz. Bu bir basari gostergesidir.

## Neden vardir?

Cunku asansor kapisi kapandiktan sonra "yanlis kat" demek, evrene karsi acilan davadir. Dava dusurulur. Sen de inersin. Yanlis katta.

## Kurulum

```bash
python3 pismanlik.py
```

Baska bagimlilik yoktur. Bagimliligi zaten asansor muzigi getirmistir.

## Kullanim ornegi

```
Gitmek istedigin kat: 4
Parmaginin ihanet edip bastigi kat: 14
Pismanlik indeksi: 191.47
```

Indeks 0 ise hayatin yolundadir.
Indeks 80+ ise artik o katta kira sozlesmesi imzala.

## Bilimsel yontem

1. Istenen kat ile basilan kat arasindaki mutlak fark alinir.
2. 13.7 sabiti ile carpilir (13.7, asansor butonlarinin ortalama ockusudur).
3. Yukari yonlu hatalar daha utanc verici kabul edilir.
4. Rastgele utanc carpani eklenir cunku evren adil degildir.
